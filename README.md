Entry for the [One Line, One Laugh](https://make.fun/c/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a) competition on [make.fun](https://make.fun).

`main.py` (Python 3 standard library only) writes a single funny line of text to `entry.txt` — one self-contained joke, short enough to read in a breath:

> My Roomba filed for emancipation: I kept calling it 'the help'.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
